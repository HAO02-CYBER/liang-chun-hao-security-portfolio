# Liang Chun Hao Security Portfolio

Personal portfolio for Liang Chun Hao, an IT Security student focused on pentesting, cloud security, and network security.

## Live Site

[liang-chun-hao-security-portfolio.vercel.app](https://liang-chun-hao-security-portfolio.vercel.app/)

## Stack

- React 19
- Vite 7
- Morphicons and Lucide icons
- CSS animations with reduced-motion support

## Local Development

```powershell
pnpm install
pnpm dev
```

Create a production build with:

```powershell
pnpm build
```
